## Objective
Add comprehensive OpenAPI 3.0 / Swagger documentation and integrate MapStruct for automatic entity-DTO mapping.

## Key Features

### OpenAPI/Swagger Documentation
- **SpringDoc OpenAPI 2.2.0**: Modern replacement for Springfox Swagger
- **Swagger UI**: Available at `/swagger-ui.html` for interactive API testing
- **OpenAPI JSON**: Available at `/v3/api-docs` for client code generation
- **Endpoint Documentation**:
  - All REST endpoints fully documented with @Operation
  - Success and error response codes specified with @ApiResponse
  - Endpoints organized by tags (@Tag)
- **Configuration**:
  - sortingoperations by HTTP method
  - Tags sorted alphabetically

### MapStruct Integration
- **Automatic Mapping**: Replace manual DTO ↔ Entity mapping with compile-time generated code
- **Performance**: Zero-reflection approach, optimized at build time
- **Type Safety**: Compile-time verification of field mappings
- **Spring Integration**: Seamless component model for dependency injection

### Framework Upgrades (Cumulative)
- Spring Boot: 2.6.7 → 3.3.0 LTS (latest LTS release)
- Java: 11 → 17 LTS (latest LTS release)
- Maven Compiler Plugin: 3.10.1 with annotation processors
- Guava: 28.1 → 33.1.0-jre

### Import Migration
- javax.persistence.* → jakarta.persistence.*
- javax.validation.* → jakarta.validation.*
- Aligns with Spring Boot 3.x ecosystem changes
